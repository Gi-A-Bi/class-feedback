# 에듀집 등록 서류

발표 평가를 에듀집(edzip.kr)에 올릴 때 쓰는 개인정보 관련 서류입니다.

| 서류 | 파일 | 쓰임 |
| --- | --- | --- |
| 개인정보처리방침 | [`public/privacy.html`](../../public/privacy.html) → <https://class-feedback-wheat.vercel.app/privacy.html> | 체크리스트의 증빙. 주소를 그대로 적어 냅니다 |
| 필수기준 체크리스트(공급자용) | [`에듀집 필수기준 체크리스트(발표 평가).pdf`](<./에듀집 필수기준 체크리스트(발표 평가).pdf>) | 에듀집에 내는 서류 |
| 체크리스트 원본 | [`checklist.html`](./checklist.html) | PDF를 다시 만들 때. 브라우저에서 열어 인쇄 → PDF로 저장 |

## 내기 전에 선생님이 확인하실 것

1. **방침이 실제로 열리는지** — 이 변경이 `main`에 합쳐져 배포된 뒤, 위 방침 주소가 열리는지 확인합니다.
2. **보유 기간** — 방침 제3조·제5조에 "해당 학년도 종료 시까지 보유, 학년도가 끝나면 학급을 지워 파기"라고 적었습니다.
   쌤툴즈의 다른 프로그램과 같은 기준입니다. 다르게 하시려면 방침과 체크리스트 1-3을 함께 고칩니다.
   자동으로 지워 주는 기능은 없으므로, **학년 말에 교사 화면에서 학급을 직접 지워야** 방침대로 됩니다.
3. **문의처** — 쌤툴즈에 공개된 주소(healthydol@gmail.com)를 적었습니다.
4. **프로그램 이름** — "발표 평가"로 적었습니다. 이름을 바꾸면 방침, 체크리스트, 쌤툴즈 소개 글을 함께 고칩니다.
5. **공식 양식** — 에듀집이 한글(HWP) 양식으로 내라고 하면, 공식 양식을 내려받아 PDF의 내용을 그대로 옮겨 적으면 됩니다.
   항목 번호(1-1 ~ 5-3)와 문구가 공식 양식과 같게 되어 있습니다.

## 학교운영위원회 심의에 대해

이 프로그램은 학생의 번호와 이름을 다루므로, 교육부 판단 순서도의 "학생의 개인정보를 수집·이용·처리합니까?"에
해당할 수 있습니다. 심의 대상인지는 학교에서 판단합니다. 쌤툴즈의 프로그램 소개 페이지 아래에 순서도가 있습니다.

## 방침에 적은 사실의 근거

| 방침에 적은 내용 | 근거 |
| --- | --- |
| 저장하는 항목 (제2조) | `src/lib/types.ts`, `src/lib/student.ts`(태블릿 브라우저 저장) |
| 교사별 분리, 평가자 익명, 목록 조회 차단, 입력 검사 (제6조) | `firestore.rules`, `tests/rules*.test.ts` |
| 학급·활동·학생을 지우면 바로 파기 (제5조) | `src/lib/classes.ts`의 `deleteClass`·`deleteStudent`, `src/lib/activities.ts`의 `deleteActivity`, `tests/rules-delete.test.ts` |
| 학생 정보는 서울 리전에 저장 (제11조) | Firestore를 `asia-northeast3`으로 만듦 (README의 C 단계) |
| 로그인 정보는 미국에서 처리 (제11조) | Firebase Authentication은 미국 데이터센터에서 운영되는 서비스로 알려져 있음. 제출 전에 Firebase의 "개인정보 보호 및 보안" 문서에서 한 번 더 확인 |
| 웹 글꼴, 호스팅 (제10조) | `index.html`(Google Fonts), Vercel 배포 |
